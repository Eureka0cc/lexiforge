- 用户调整范围为先本地可用，不安排云部署或线上 7 天试运营；支付仍仅 Sandbox。
- V7 新增会话、一次性操作凭据和加密邮件队列。邮箱验证、密码重置、账户页面已接入；dev/test 以本地文件投递测试邮件，位置 `tmp/auth-mail/`，未连接真实 SMTP。
- 密码重置立即撤销全部会话；退出撤销当前会话及刷新后继。用户行锁保证刷新轮换只有一次成功，旧 Cookie 退出仍能撤销其后继。认证 POST 校验浏览器 Origin，Cookie 支持 Secure 配置。
